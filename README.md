# Guess-My-Number-Game
🎲 Guess My Number! 
A fun and interactive number guessing game built with HTML, CSS, and JavaScript. 
Test your luck and logic by guessing the secret number between 1 and 20. 
The game provides instant feedback on your guesses and keeps track of your score and high score!

Features:
Random Number Generation: A secret number is generated between 1 and 20 for each game session.
Instant Feedback: Get hints if your guess is too high, too low, or correct!
core System: Players start with 20 points and lose 1 point per incorrect guess.
High Score Tracking: The game saves the highest score achieved.
Restart Option: Click the "Again!" button to reset the game and try again.
Modern & Responsive UI: Styled with CSS for a retro gaming feel.

Technologies Used:
HTML: Structuring the game layout.
CSS: Styling and animations for an engaging experience.
JavaScript: Implementing game logic, user interactions, and DOM manipulation.

How to Play:
Click the "Check!" button after entering your guess.
Receive feedback if your guess is too high or too low.
Keep guessing until you find the correct number.
Try to achieve the highest possible score!
Click "Again!" to restart the game
